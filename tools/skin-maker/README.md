# ゆかナビ スキンメーカー (Web 版)

きせかえスキンの zip をブラウザだけで作れるツール。
ファイルの選択 (D&D 可)・プレビュー・skin.json 生成・zip ダウンロードまで
**すべてブラウザ内で完結**し、ファイルはどこにも送信されない。
サーバー処理が無いので、静的ファイルとしてそのまま公開できる。

## できること

- skin.json の全キーに対応 (2026-07 拡張スキーマ):
  背景 (複数 + 昼夜 + 季節×昼夜)・キャラ (複数、目閉じ・表情差分・個別セリフ)・
  予約完了ポーズ・BGM (通常 + 昼夜 + 季節×昼夜)・効果音 5 種・
  セリフ (通常 + 朝/夕方/夜)・テーマ色・作者名・サムネイル・起動画面
- ホーム画面風プレビュー (タップで表情巡回・まばたき・吹き出し・テーマ色)
- 時刻・季節シミュレーター: 月と時刻を選ぶと、どの背景・BGM・セリフ帯が
  使われるかを表示 (アプリのフォールバック順を再現)。BGM の試聴も可能
- **既存 zip の読み込み・編集**: 配布済みスキンやアプリの「共有」で書き出した
  zip をドロップすると全項目がフォームに復元される。このツールが知らない
  将来のキーや未参照ファイルも zip に保持されるので、古いツールで編集しても
  データが消えない
- 素材のファイル名は役割ベースで自動リネーム (bg_1.png / chara_1_blink.png 等)。
  日本語ファイル名による zip の文字化け問題を避ける

## ykr.moe への公開手順

このフォルダの 4 ファイルをそのままアップロードするだけ:

```
https://ykr.moe/yukanavi_skin_maker/
├─ index.html
├─ skin-maker.css
├─ skin-maker.js
└─ jszip.min.js
```

サーバープログラム (PHP 等) は不要。更新もファイルを置き換えるだけ。

## ローカルでの動作確認

`index.html` をブラウザで直接開けば動く。開発時にキャッシュ等で困る場合は
簡易サーバーで:

```bash
python -m http.server 8765 --directory tools/skin-maker
```

## 既知の注意点

- **手作りの zip はパス区切りに注意**: ZIP 仕様の区切りは `/` だが、Windows のツールで
  作ると `\` になることがある。読み込み側で吸収しているのでスキンメーカーとアプリは
  どちらでも扱えるが、他のツールに渡す場合は `/` の zip を用意するのが無難
- **試聴できない形式がある**: ブラウザによっては ogg などを再生できない (Safari の ogg 等)。
  その場合はダイアログで知らせる。**アプリ側では再生できる**ので、スキンの設定としては問題ない

## 技術メモ

- 依存は同梱の [JSZip 3.10.1](https://stuk.github.io/jszip/) (MIT) のみ。ビルド不要
- skin.json の仕様は `docs/skin-spec.md` (正はアプリの `SkinManager.cs`)。
  スキーマにキーを足したときは `skin-maker.js` の `TIMED_KEYS` / `SE_KEYS` /
  `KNOWN_KEYS` とフォーム生成部、および `docs/skin-spec.md` を更新する
- プレビューの背景調整 (回転/ズーム/位置) は CSS transform による近似で、
  アプリの厳密な cover 計算とは僅かに差がある (実機確認を推奨)
- 作った zip はアプリの「取り込む (zip)」でそのまま使える。DLC 配布は
  `docs/skin-dlc.md` の手順どおり `yukanavi_dlc/<コード>.zip` に置く
