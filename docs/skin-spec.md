# ゆかナビ きせかえスキン仕様書

きせかえスキンの全仕様をまとめたリファレンス。
実装上の正は `Assets/YukaNavi/Scripts/Core/SkinManager.cs` (スキーマ = `SkinDef`)。
配布 (DLC) の運用手順は [skin-dlc.md](skin-dlc.md)、ユーザー向けの操作説明は
[user-manual.md](user-manual.md) §9 を参照。

- 2026-07: 季節×昼夜 BGM/背景・表情/まばたき差分・完了ポーズ・SE・時間帯セリフ・
  作者メタ・サムネイルを追加 (アプリ側の対応バージョン以降で有効。旧バージョンは
  未知キーを無視して従来どおり動く)

## 1. スキンの基本

| 項目 | 内容 |
|---|---|
| 置き場所 | `Application.persistentDataPath/skins/<フォルダ名>/` |
| スキン ID | フォルダ名がそのまま ID (選択状態の保存キー)。zip 取り込み時に同名があれば `_2`, `_3`… が付く |
| 必須ファイル | `skin.json` のみ。無いフォルダはスキン一覧に出ない |
| 表示名 | `skin.json` の `name`。空なら ID が表示される |
| その他のファイル | すべて任意。参照が壊れている・ファイルが無い箇所は項目単位でデフォルトにフォールバックし、アプリは止まらない |
| 適用 | きせかえ画面で選択。選択中スキン ID は端末 (PlayerPrefs `yukanavi.skin_id`) に保存 |
| Windows Editor の実体パス | `%USERPROFILE%\AppData\LocalLow\bee7813993\ゆかナビ\skins\` |

ファイル参照 (`file` / `eyes_closed` 等) はスキンフォルダからの相対パスで、
`..` を含む参照は無効 (フォルダ外は読めない)。サブフォルダは可。

## 2. skin.json リファレンス

### 2.1 フル構成例

```jsonc
{
  "name": "スキン名",
  "author": "作者名",                 // 一覧に表示 (任意)
  "description": "説明",              // 予備メタ (任意)

  // ---- 背景 ----
  "background":  { "type": "image", "file": "bg.png" },   // 単数 (旧形式。backgrounds と併用可)
  "backgrounds": [                                         // 複数。ホーム背景タップで巡回
    { "type": "video", "file": "bg1.mp4" },
    { "type": "image", "file": "bg2.png",
      "rotation": 90, "zoom": 1.5, "offset_x": 0.1, "offset_y": 0 }
  ],
  "background_day":   { "type": "image", "file": "bg_day.png" },   // 昼夜背景
  "background_night": { "type": "image", "file": "bg_night.png" },
  "background_spring_day": { "type": "image", "file": "bg_sd.png" }, // 季節×昼夜背景 (8種)
  // background_{spring|summer|autumn|winter}_{day|night}

  // ---- キャラ ----
  "character":  { "type": "image", "file": "chara.png" },  // 単数 (旧形式) / {"type":"none"} でキャラなし
  "characters": [                                          // 複数。タップで表情一巡→次キャラ
    { "type": "image", "file": "chara1.png", "scale": 1.0,
      "talk": ["キャラ1のセリフ"],
      "eyes_closed": "chara1_blink.png",                   // 目閉じ差分 → まばたき
      "expressions": [                                     // 表情差分
        { "file": "chara1_smile.png", "talk": ["この表情のセリフ"] }
      ] },
    { "type": "image", "file": "chara2.png" }
  ],
  "pose_complete": { "type": "image", "file": "pose.png" },  // 予約完了画面のポーズ絵

  // ---- BGM ----
  "bgm":       { "type": "audio", "file": "bgm.ogg" },     // 通常
  "bgm_day":   { "type": "audio", "file": "bgm_day.ogg" }, // 昼夜
  "bgm_night": { "type": "audio", "file": "bgm_night.ogg" },
  "bgm_spring_day": { "type": "audio", "file": "sd.ogg" }, // 季節×昼夜 (8種)
  // bgm_{spring|summer|autumn|winter}_{day|night}

  // ---- 効果音 ----
  "se_tap":        { "type": "audio", "file": "tap.ogg" },
  "se_confirm":    { "type": "audio", "file": "confirm.ogg" },
  "se_error":      { "type": "audio", "file": "error.ogg" },
  "se_transition": { "type": "audio", "file": "transition.ogg" },
  "se_complete":   { "type": "audio", "file": "complete.ogg" },

  // ---- その他 ----
  "record": { "type": "image", "file": "record.png" },     // リモコンのレコード盤
  "talk": ["通常セリフ1", "通常セリフ2"],
  "talk_morning": ["朝のセリフ"],
  "talk_evening": ["夕方のセリフ"],
  "talk_night":   ["夜のセリフ"],
  "theme": { "primary": "#7B5CD6" },                       // テーマ色 (#RRGGBB)
  "layout": { }                                            // ホーム配置。アプリが自動管理 (手書き非推奨)
}
```

### 2.2 トップレベルキー一覧

| キー | 型 | 説明 |
|---|---|---|
| `name` | string | 表示名。空なら ID |
| `author` | string | 作者名。きせかえ一覧の名前の下に表示 |
| `description` | string | 説明 (現状 UI 表示なし。メタ情報) |
| `background` | Layer | 単数背景 (旧形式)。`backgrounds` と併用時は先頭扱い |
| `backgrounds` | Layer[] | 複数背景。背景タップで巡回 |
| `background_day` / `background_night` | Layer | 昼夜で自動切替する背景 |
| `background_<季節>_<昼夜>` ×8 | Layer | 季節×昼夜で自動切替する背景 |
| `character` | Layer | 単数キャラ (旧形式)。`{"type":"none"}` でキャラ非表示 |
| `characters` | Layer[] | 複数キャラ。タップで表情一巡→次キャラ |
| `pose_complete` | Layer(image) | 予約完了画面のポーズ絵 |
| `bgm` | Layer(audio) | 通常 BGM |
| `bgm_day` / `bgm_night` | Layer(audio) | 昼夜 BGM |
| `bgm_<季節>_<昼夜>` ×8 | Layer(audio) | 季節×昼夜 BGM |
| `se_tap` / `se_confirm` / `se_error` / `se_transition` / `se_complete` | Layer(audio) | 効果音差し替え (タップ / 決定 / エラー / 画面切替 / 予約完了) |
| `record` | Layer(image) | リモコン・ダッシュボードのレコード盤 |
| `talk` | string[] | 通常セリフ (1要素 = 1つ。タップでランダム表示) |
| `talk_morning` / `talk_evening` / `talk_night` | string[] | 時間帯セリフ。`talk` と合算して抽選 |
| `theme` | object | `{ "primary": "#RRGGBB" }`。1色から UI 全色を導出 |
| `layout` | object | ホームパーツ配置。**アプリが書き戻す** (§5.10) |

季節は `spring` / `summer` / `autumn` / `winter`、昼夜は `day` / `night`。

### 2.3 Layer (SkinLayer) のフィールド

| フィールド | 型 | 既定 | 使う場所 | 説明 |
|---|---|---|---|---|
| `type` | string | — | 全部 | `image` / `video` / `audio` / `none`。`none` はキャラ非表示専用 (`file` 不要)。`live2d` は予約 (未実装、§12) |
| `file` | string | — | 全部 | スキンフォルダからの相対パス |
| `scale` | float | 1 | キャラ | 表示倍率。0.3〜2.0 にクランプ。**1枚目のキャラの値だけが使われる** |
| `talk` | string[] | — | キャラ | そのキャラ専用セリフ |
| `eyes_closed` | string | — | キャラ | 目閉じ差分のファイル。指定するとまばたきする |
| `expressions` | Expression[] | — | キャラ | 表情差分 (下記) |
| `rotation` | float | 0 | 背景 | 回転 (度)。90 単位を想定 |
| `zoom` | float | 1 | 背景 | 1 = 画面を覆うちょうど (cover)。1.0〜4.0 にクランプ |
| `offset_x` / `offset_y` | float | 0 | 背景 | 位置調整。画面幅 / 高さに対する比率 |

Expression (`expressions` の要素):

| フィールド | 型 | 説明 |
|---|---|---|
| `file` | string | 表情画像。立ち絵と同ポーズ・同解像度の透過 PNG 推奨 |
| `talk` | string[] | この表情のときだけのセリフ (任意) |

### 2.4 規約ファイル (skin.json に書かない)

フォルダに置くだけで有効になるファイル。ファイル名固定。

| ファイル | 用途 |
|---|---|
| `splash.png` | 起動タイトル画面の背景。画面全体に cover 表示 (白下地、はみ出しあり) |
| `thumbnail.png` | きせかえ一覧のサムネイル (約 84×84 で表示。正方形推奨) |

## 3. 時刻・季節の区分

| 区分 | 定義 | 使う機能 |
|---|---|---|
| 昼 | 6:00〜17:59 | BGM・背景の `_day` |
| 夜 | 18:00〜翌 5:59 | BGM・背景の `_night` |
| 春 | 3〜5月 | `_spring_*` |
| 夏 | 6〜8月 | `_summer_*` |
| 秋 | 9〜11月 | `_autumn_*` |
| 冬 | 12〜2月 | `_winter_*` |
| 朝 | 5:00〜10:59 | `talk_morning` |
| 夕方 | 17:00〜21:59 | `talk_evening` |
| 夜 (セリフ) | 22:00〜翌 4:59 | `talk_night` |

- 判定は端末のローカル時刻。セリフの時間帯は BGM の昼夜と**別の区分** (挨拶の自然さを優先)
- 11:00〜16:59 は通常セリフのみの時間帯
- 季節はアニメ期のインデックス区分 (1〜3月 = 冬) とは別物

## 4. フォールバック (優先順位)

すべてのキーは任意。指定が無い・ファイルが読めない場合は次の候補に落ちる。

| 対象 | 優先順 (左が強い) |
|---|---|
| BGM | `bgm_<季節>_<昼夜>` → `bgm_day`/`bgm_night` → `bgm` → アプリ組み込み (季節曲があれば季節曲 → 基本ループ曲) |
| 背景 | `background_<季節>_<昼夜>` → `background_day`/`background_night` → `backgrounds`/`background` → デフォルト動画 → デフォルト静止画 |
| セリフ | 表示中の表情の `talk` → キャラの `talk` → スキンの (時間帯 talk + `talk` の合算) → デフォルトのゆかりちゃんセリフ (**カスタムキャラのときは無言**) |
| 完了ポーズ | `pose_complete` → キャラの 1 枚目 → デフォルト (ゆかりちゃん) |
| SE | `se_*` → アプリ標準の音 |
| レコード盤 | `record` → アプリ標準の盤 → 実行時生成の簡易盤 |
| テーマ色 | `theme.primary` → 既定の紫 (不正な値も既定へ) |
| 起動画面 | `splash.png` → アプリ標準のスプラッシュ |

- 時間帯 BGM / 背景は「指定があるのに読めない」場合もフォールバックする
- 時間帯セリフは合算方式: `talk_morning` があっても通常 `talk` は抽選から外れない

## 5. 表示・再生の挙動詳細

### 5.1 背景

- 表示は cover (画面を覆う)。`rotation` / `zoom` / `offset_x/y` で調整可
- 動画 (`type: "video"`) は無音・ループ再生。静止画とも背景タップの巡回対象
- **タップ巡回**: 背景リストが 2 枚以上のとき、ホームの何もない部分をタップで次へ。
  選択位置はスキンごとに端末保存 (PlayerPrefs `home.bg_index.<ID>`)
- **時間帯背景**があるスキンでは、その時刻の解決結果がリスト先頭 (= 自動枠) になる。
  時間帯またぎは分単位で検知され、**自動枠を表示中のときだけ**背景が切り替わる
  (手動で巡回した背景は勝手に変わらない)

### 5.2 マスコット (キャラ)

- 表示枠は 740×1110 × `scale` (基準解像度 1080×1920 の座標系)。下端中央基準、
  縦横比は維持 (preserveAspect)
- **タップ巡回**: 「現在キャラの 立ち絵 → 表情1 → 表情2 → … を一巡 → 次のキャラの立ち絵」。
  デフォルトのゆかりちゃんも同じ仕組み (1 キャラ + 表情 3 種)
- **まばたき**: `eyes_closed` があるキャラの立ち絵表示中のみ。2.5〜6 秒間隔でランダム、
  0.12 秒目を閉じる (初回は表示から 2〜4 秒後)
- 常時アニメ: 呼吸 (ゆっくり伸縮 + 微傾き)、タップ時のスクイーズ。カスタムキャラも同じ
- 読めない表情はスキップされ、そのキャラの巡回から抜ける (talk の対応もずれない)
- ホームの移動モード中はタップ演出が止まる

### 5.3 セリフ

- タップごとに §4 の優先順で候補リストを決め、その中からランダムに 1 つ表示
- 吹き出しは約 2.2 秒で自動的に消える。長文は自動で折り返し (吹き出しが縦に伸びる)
- カスタムキャラでセリフが 1 つも無い場合は無言 (デフォルトのセリフは流用されない。
  ゆかりちゃんの人格前提のセリフのため)

### 5.4 BGM

- ループ再生。既定はミュート (カラオケの邪魔をしない)、音量既定 35%
  (ホーム右上のスピーカーボタンで変更、端末保存)
- 対応形式: mp3 / ogg / wav。**m4a / aac は不可** (Unity のランタイム読み込み非対応)
- 切替タイミング: スキンの適用・作成・編集・取り込み・削除、時間帯またぎ (分単位)、
  バックグラウンド復帰時。クロスフェードはなし (即時切替)
- 自然ループする音源推奨 (16 秒程度〜)。動画プレビュー再生中は自動で一時ミュート

### 5.5 効果音 (SE)

- 5 種: タップ / 決定 / エラー / 画面切替 / 予約完了。対応形式は BGM と同じ
- スキン適用時に事前ロードされるため再生遅延なし。無い音はアプリ標準
- BGM ミュート中は SE も鳴らない (アプリ全体ミュートの扱い)。SE 音量は別スライダー

### 5.6 レコード盤 (`record`)

- リモコン画面とダッシュボード画面の回転するレコード盤を差し替える
- 画像はそのまま表示される (円形マスクは無い)。**正方形キャンバスに円形に描いた
  透過 PNG** を推奨 (1024×1024 目安)

### 5.7 テーマ色 (`theme.primary`)

- `#RRGGBB` 1 色から UI 全色を HSV で自動導出する:
  濃色 (文字・強調) = 明度 55%、淡色 (ボタン地) = 彩度 22%、
  画面背景 = 彩度 12%、半透明オーバーレイ = 彩度 8% + α0.6
- 適用範囲: ボタン・見出し・ナビバー・パーティクル色など UI 全般
- 変更時は全画面が再構築される (UI は生成時に色を焼き込むため)

### 5.8 起動画面 (`splash.png`)

- 起動タイトル画面の背景を差し替える。画面全体に cover 表示 (中央基準、白下地)
- 縦 1080×1920 推奨。画面比が異なる端末では上下または左右が見切れる
  (重要な絵柄は中央 820×1440 に収めるのが安全)

### 5.9 予約完了ポーズ (`pose_complete`)

- 予約完了のオーバーレイに表示されるポーズ絵。§4 の 3 段フォールバック
- ポップ演出 (0.35 秒で拡大) はアプリ側の共通挙動

### 5.10 ホーム配置 (`layout`)

- ホームの 3 パーツ (`clock` / `ticker` / `mascot`) の表示・位置・大きさ:
  `{ "visible": true, "x": 0, "y": 160, "scale": 1.0 }`
- **アプリが自動で書き戻すフィールド** (ホームの長押し移動・きせかえ画面のトグルで変更)。
  手書きは非推奨だが、配布スキンに初期配置を入れておくことはできる
- 座標はホーム画面の Canvas 座標 (基準 1080×1920)、scale は 0.5〜2.0
- カスタムスキンでは skin.json に保存され、共有 (zip) にも配置が付いて回る。
  デフォルトスキンでは端末 (PlayerPrefs) 保存

## 6. ファイル形式と推奨仕様

| 種別 | 対応拡張子 | 推奨 |
|---|---|---|
| 画像 | png / jpg / jpeg / webp / gif | 透過が要る箇所 (キャラ・表情・レコード盤) は png |
| 動画 | mp4 / webm / mov | mp4 (H.264)、縦 1080×1920、音声なし |
| 音声 | mp3 / ogg / wav | ogg。**m4a / aac は不可** |

| 素材 | 推奨サイズ |
|---|---|
| 背景 (縦) | 1080×1920 |
| キャラ立ち絵・表情・目閉じ | 縦長透過 PNG。デフォルト素材は 1024×1536。**表情・目閉じは立ち絵と同ポーズ・同解像度** (同じ枠に表示されるだけで位置合わせはされない) |
| 完了ポーズ | 立ち絵と同スケール |
| レコード盤 | 1024×1024、円形に描いた透過 PNG |
| splash.png | 1080×1920 (安全域は中央 820×1440) |
| thumbnail.png | 正方形 (256×256 程度で十分) |

## 7. 制作チェックリスト

全機能を使うスキンを作るときに用意するもの。すべて任意なので、
作らなかったものは §4 のフォールバックでデフォルトに落ちる。

### 7.1 画像 (フル構成で最大 18 ファイル)

| 素材 | 枚数 | 備考 |
|---|---|---|
| 通常背景 | 1〜 | 2枚以上でタップ巡回。mp4 動画も可 |
| 季節×昼夜背景 | 8 | 春夏秋冬 × 昼夜。動画も可 |
| 昼夜背景 | (0) | **季節8枚を作るなら不要** (季節が常に優先され出番がない) |
| キャラ立ち絵 | キャラ数 | 縦長透過 PNG |
| 目閉じ差分 | キャラ数 | 立ち絵と同ポーズ・同解像度。これがないとまばたきしない |
| 表情差分 | キャラ数 × 表情数 | ゆかりちゃん相当なら 3 (笑顔・ウィンク・驚き) |
| 予約完了ポーズ | 1 | 未指定だとキャラ1枚目が流用される |
| レコード盤 | 1 | 円形に描いた透過 PNG (マスクはされない) |
| `splash.png` | 1 | 起動画面 |
| `thumbnail.png` | 1 | 一覧サムネイル |

### 7.2 音声 (フル構成で最大 14 ファイル)

| 素材 | 本数 | 備考 |
|---|---|---|
| 季節×昼夜 BGM | 8 | 自然ループする ogg |
| 通常 BGM | 1 | 季節8曲が揃うと出番がないが、**季節を一部しか作らない場合の受け皿**になる |
| 昼夜 BGM | (0) | 季節8曲を作るなら不要 (画像と同じ理由) |
| SE | 5 | タップ / 決定 / エラー / 画面切替 / 予約完了 |

### 7.3 テキスト (skin.json に直接書く)

| 項目 | 目安 |
|---|---|
| 通常セリフ (`talk`) | 3〜5個 |
| 時間帯セリフ (朝・夕方・夜) | 各 1〜2個 |
| キャラ別セリフ | キャラ数分 (任意) |
| 表情別セリフ | 表情数分 (任意) |
| `name` / `author` / `description` | — |
| `theme.primary` | 1色 |

### 7.4 構成パターン別の目安

| 構成 | 画像 | 音声 | 合計 |
|---|---|---|---|
| ミニマム (背景 + キャラ + セリフ + 色) | 2 | 0 | 2 ファイル + skin.json |
| デフォルトテーマ同等 (立ち絵 + 目閉じ + 表情3 + 完了ポーズ + BGM + セリフ4系統) | 6 | 1 | 7 ファイル + skin.json |
| フル構成 (1キャラ) | 18 | 14 | 32 ファイル + skin.json (zip 30〜60MB 目安) |

### 7.5 作る順番のヒント

- 体感効果が大きい順: **立ち絵一式 (目閉じ + 表情) → 背景 → テーマ色 → BGM →
  セリフ → 季節バリエーション → SE**。SE は手間の割に気づかれにくい
- ボリュームの半分は季節系 (絵8枚 + 曲8本)。「春だけ作る」も成立するが、
  **季節を部分的に作るときは通常背景・通常 BGM を必ず入れる** (穴の時間帯の受け皿)
- 目閉じ・表情は「同ポーズで顔だけ違う」を守らないとタップ時にガタつく
  (位置合わせは自動でされない)
- キャラを増やすときは、完了ポーズが「キャラ1枚目」固定になる点に注意。
  `pose_complete` で明示指定するのが安全
- 各項目は `tools/skin-maker/` のフォームの並びとほぼ一対一なので、
  ツールを上から埋めていけばフル構成になる

## 8. バリデーション

きせかえ一覧に出る際に書式チェックされ、問題は ⚠ で表示される (制作支援用)。

| 状態 | 挙動 |
|---|---|
| skin.json がパース不能 | 一覧に赤背景 + ⚠ で出る。**適用不可** (タップで理由表示) |
| 書式の問題あり | ⚠ 付きで表示。**適用は可能** (問題箇所だけデフォルトにフォールバック)。適用時に問題点をトースト表示 (最大 3 件 + 件数) |

検出される問題: `type` が不正 / `file` 未指定 / ファイル実体なし /
audio に m4a・aac / type と拡張子の食い違い (image に動画ファイル等) /
`eyes_closed`・`expressions` のファイル実体なし。

Unity Editor ではメニュー「YukaNavi > スキン検証」で一括チェック・時刻別の
フォールバック解決確認・全キー入りテストスキン生成ができる。

## 9. 配布・入出力

| 操作 | 仕様 |
|---|---|
| zip 取り込み | zip 直下または**フォルダ 1 階層下**の skin.json を探す。無ければ失敗。フォルダ名は zip 名から (衝突時 `_2`…) |
| 共有 (書き出し) | スキンフォルダを丸ごと zip 化。そのまま配布・再取り込み可 |
| DLC コード | `https://ykr.moe/yukanavi_dlc/<コード>.zip` を取得して取り込む。コードは大文字化される。4〜32 文字。認証なし (詳細は [skin-dlc.md](skin-dlc.md)) |
| アプリ内編集 | 編集モーダルが扱うのは単数フィールド (name / background / character / bgm / record / talk / theme) のみ。**拡張フィールド (複数指定・季節/昼夜・SE・時間帯セリフ等) は編集後も skin.json に維持される** |
| 後方互換 | 旧バージョンのアプリは未知キーを無視して動く。新キーを使った skin.json も安全 |

## 10. 制作ツール

| ツール | 場所 | 用途 |
|---|---|---|
| スキンメーカー (Web) | `tools/skin-maker/` (ykr.moe に静的公開可) | ブラウザだけでファイル選択 → プレビュー → zip 生成。既存 zip の読み込み編集も可 |
| アプリ内エディタ | きせかえ画面「スキンを作る / 編集」 | 単数フィールドの簡易作成 |
| Editor 検証メニュー | Unity メニュー「YukaNavi > スキン検証」 | ValidateSkin 一括 / 時刻別解決の表示 / テストスキン生成 |
| サンプルスキン | `art/sample_skins/yukari_four_seasons/` | 季節背景スキンの実例 (make_zip.ps1 で zip 化) |
| 自動生成 readme | `skins/readme.txt` (アプリが生成) | 端末内で読める簡易版仕様 |

## 11. 関連: デフォルトテーマ拡張パック

スキンとは**別系統**の仕組み。デフォルト (ゆかりちゃん) テーマの季節 BGM 音源や
セリフ追加を、アプリのバージョンアップなしで配信する
(`persistentDataPath/default_theme/`、解決順はパック → Resources → 基本素材)。
スキンが指定されている項目はスキンが常に優先される。
詳細は [default-theme-pack.md](default-theme-pack.md)。
