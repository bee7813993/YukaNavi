# 機材係提供コンテンツ (アプリ内おしらせ) 仕様

ゆかナビのアプリ内に、機材係 (ゆかりの運用者) が書いたお知らせを表示する仕組み。
イベントの案内・縛りテーマの告知・曲リストへのリンクなどを、アプリを更新せずに
会場側から出せる。

## 書き方 (機材係向け)

ゆかりの設定画面 (init.php) にある
**「リクエスト一覧（トップ）画面表示メッセージ」** (HTML 記述可) に、
**`class="yukanavi-notice"` を付けた要素**を書く。それだけで動く。

```html
<!-- Web 版のトップページにも、アプリにも出る例 -->
<div class="yukanavi-notice">
  <h3>今日は 90 年代アニソン縛り！</h3>
  <p>まずはこれ → <a href="./search_bs5.php?searchword=スレイヤーズ">スレイヤーズで検索</a></p>
</div>
```

- マーカー class が付いた要素**だけ**がアプリに表示される (付けなければ従来どおり
  Web 版にしか出ない)。複数あれば文書順に連結して表示する
- `#yukarihost#` はサーバーがホスト名へ置換したうえでアプリに渡る
- Web 版に出したくない (アプリ専用にしたい) 場合は、ゆかり側の CSS で
  `.yukanavi-notice { display: none; }` などを併用する

## アプリでの表示のされ方

- お知らせがあると、**メニューに「おしらせ」**(曲をさがす・予約一覧と同列) が現れ、
  **ホーム上部に「おしらせがあるよ♪」チップ**が出る。無い会場では一切表示されない
- 表示は WebView ではなく UGUI の自前描画。対応タグは限定される:

| 種類 | タグ |
|------|------|
| 見出し | `h1`〜`h6` (太字・サイズ違いで表示) |
| 段落・区切り | `p` `div` `br` `hr` |
| 箇条書き | `ul` `ol` `li` (番号・「・」付きの行になる) |
| 装飾 | `b` `strong` `i` `em`、`span`/`font` の色指定 (`color` 属性 / `style="color:..."`) |
| リンク | `a href` (下記) |
| 画像 | `img src` (相対 URL は接続先サーバー基準で解決) |

- 上記以外のタグは無視され、中身のテキストだけが残る。`script`/`style` は中身ごと捨てる
- **リンクは行として独立して表示**される (文中に埋め込んだ場合も、その位置で
  「▶ ラベル」の行になる)。文の途中にリンクを挟むより、行として書くときれいに出る

## リンクの動作

- **接続中のゆかりサーバーの検索ページ** (ファイル名が `search` で始まるページ) への
  リンクは、外部ブラウザに出ずに**アプリ内の検索**へつながる
  - 検索ワードは `searchword` / `anyword` / `keyword` / `word` クエリから拾う
  - `search_listerdb〜` へのリンクはアニソン DB 検索、それ以外 (`search.php`
    `search_bs5.php` 等) はファイル名 (Everything) 検索として実行される
  - ワードが無いリンクは検索トップ画面を開く
- それ以外の http(s) リンクは InAppBrowser (iOS はアプリ内シート / その他は既定
  ブラウザ) で開く

## 取得の仕組み (アプリ実装)

- 表示メッセージは API (`/api/`) に公開されていないため、アプリは Web 版の
  **`requestlist_only.php`** (新旧どちらのサーバーにもある) の HTML を取得し、
  マーカー class 付き要素を抽出する (`NoticeService` / `NoticeHtml`)
- 取得タイミング: 起動時・ホーム表示時 (5 分間隔)・おしらせ画面を開いたとき (毎回)。
  サーバー (部屋) を切り替えると取り直す
- 通信に失敗したときは前回の内容を保つ (次の取得で追い付く)

## 制約・注意

- CSS レイアウト・テーブル表示・動画埋め込みには対応しない。凝った内容は画像 1 枚
  (`img`) にして貼るのが確実
- 文字色はアプリの白いカード上に描かれるため、暗めの色だけが解釈される
  (白など読めない色名は無視される)
- お知らせの有無はページの HTML から判定するため、easyauth (かんたん認証) の
  部屋でもアプリの接続設定が正しければ表示される
